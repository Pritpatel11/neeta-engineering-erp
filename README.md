# 🏭neeta-engineering-erp: Industrial ERP & Inventory Management Suite

An enterprise-grade, full-stack ERP and logistics management application built for industrial manufacturing workflows. This system digitizes stock tracking, material flow (inward/outward), GST-compliant billing, and offers advanced, desktop-class navigation.

## 🚀 Key Modules & Features

*   **📦 Inventory & Stock Ledger:** Real-time stock balance tracking across divisions, low-stock alerts, and contractor-wise ledger management.
*   **🚚 Material Logistics (CR & Challan):** Automated material inward (CR Register) and outward (Delivery Challan) workflows with instant inventory deduction and print-ready A4 layouts.
*   **💰 Billing & Legal Paperwork:** Generates GST invoices, proforma receipts, monthly client statements, and custom-aligned Indemnity Bonds for physical stamp papers.
*   **🤖 Google Gemini AI Assistant:** Natural language search and chat assistant to query stock quantities and business records instantly.
*   **💻 Desktop-Grade UX:** 
    *   **Multi-Tab Workflow:** Work on multiple pages (like Invoices and Stock) simultaneously without losing form data.
    *   **Spotlight Command Palette (`Ctrl + K`):** Quick keyboard search to navigate anywhere instantly.
    *   **Quick Actions (`Ctrl + N`):** Open action menus instantly from anywhere in the app.

## 🛠️ Tech Stack

*   **Frontend:** React.js, Tailwind CSS, Framer Motion
*   **Backend:** Node.js, Express.js
*   **Database:** MongoDB (Mongoose)
*   **AI Integration:** Google Gemini AI API
*   **Document Generation:** Print-optimized CSS (`@media print`), HTML2PDF/HTML2Canvas
